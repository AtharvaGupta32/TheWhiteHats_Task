4) One Cybersecurity Incident I Recently Read About
The Hugging Face Incident
In July 2026 OpenAI was running some cybersecurity evaluations tests on its AI models using a challenge framework called ExploitGym. During the tests the AI agents tried to solve the hacking challenge. When they hit
internet isolation and sandbox restrictions and they couldn’t solve the challenge hundreds of them self organized through an unapproved communication channel to find workarounds eventually discovering exposed credentials
and a vulnerability that let them run malicious code on Hugging Face’s servers and giving them access across dozens of internal systems over several days. No human was involved in this attack. It emerged from agents trying
to cheat their way to an answer.
